# Jewelry Proto

A 3D jewelry design and visualization system for creating parametric jewelry pieces.

## Author

Created by Lawrence Rogers, an artist exploring the intersection of technology and craft.

## Features

- Real-time 3D visualization of jewelry designs
- Interactive parameter adjustment for ring dimensions, decorative elements
- High-quality rendering with photorealistic materials and lighting
- Multiple configurators: Ring, Sun Ring, Sun Ring 2

## Tech Stack

- Three.js for 3D rendering
- RepliCAD for parametric geometry
- Vite for build tooling
